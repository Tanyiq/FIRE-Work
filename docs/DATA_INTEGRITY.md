# 历史数据不可破坏原则

beta 1.0 起，FIRE Work 将“当前事实”和“历史记录”分开处理。

## 财富资产与快照

- 资产列表表示当前状态，可以新增、修改或删除。
- 每次资产变化只新增或更新当天快照。
- 同一天是一个可修正的工作区，多次变化合并为一份快照。
- 以前日期的快照不会因当前资产删除、改名或改金额而被回写或删除。
- 生成报告时，如果当天还没有快照，会先建立当天快照，避免覆盖此前日期的报告。

## 报告

- 已生成的财富报告独立保存在 Storage。
- 同一天重复生成会更新当天报告，这是同日合并规则的一部分。
- 此前日期的报告不会被新的资产操作回写。
- 年度回顾属于派生视图，不写入 Storage；它始终根据受保护的快照和当前已校正的档案重新计算。

## 人生收藏

- `createdAt` 表示收藏加入档案的时间，更新收藏时保持不变，因此年度新增数量的归档年份稳定。
- `startDate`、`retiredDate`、金额和状态属于可校正事实。
- 修改生命周期后，陪伴天数、每日成本和年度最大消费展示会重新计算。
- 删除收藏不会删除财富快照或既有财富报告；实时生成的年度派生视图会反映当前档案。

## 备份恢复

- JSON 恢复属于用户明确发起的完整档案替换，是历史保护规则的唯一批量覆盖入口。
- 恢复前完成结构校验；写入失败时回滚原数据。
- 恢复前建议先导出当前档案。
