# 退休计划（FIRE Work）

一款使用微信原生小程序和 TypeScript 开发的个人财富成长档案。

它不提供股票行情、投资预测或买卖建议，而是帮助用户理解三个问题：

- 当前拥有多少财富自由度；
- 距离目标生活还有多远；
- 曾经的消费和经历是否创造了值得的人生。

## 当前功能

### 自由地图

- 选择 Lv1–Lv4 目标生活等级；
- 根据财富管家中的资产总额计算自由等级和进度；
- 展示当前资产、目标资产和目标差值；
- 展示过去一年的资产、自由进度和人生收藏变化。

### 财富管家

- 支持活钱、定存、基金、红利资产、股票、黄金和其他资产；
- 支持资产新增、修改和删除；
- 自动计算资产总额；
- 资产变化后自动保存每日财富快照；
- 使用微信原生 Canvas 展示月度和年度资产趋势。

### 人生博物馆

- 支持实物、经历、人生事件和收益事件；
- 支持 `active` 和 `retired` 状态；
- 计算使用天数和每日成本；
- 已结束或已牺牲收藏使用完整生命周期计算最终每日成本。

### 财富报告

- 比较相邻日期的财富快照；
- 展示资产变化、自由进度变化和新增人生收藏；
- 由用户选择财富变化来源；
- 使用本地规则模板生成总结；
- 同日重复生成会更新本期报告，不产生重复记录。

## 技术方案

- 微信原生小程序；
- TypeScript；
- WXML + WXSS；
- 微信本地 Storage；
- 原生 Canvas；
- 无后端、无云数据库、无第三方图表依赖。

## 项目结构

```text
miniprogram/
├── models/      领域数据结构
├── services/    本地存储和业务逻辑
├── utils/       格式化和绘图工具
├── pages/
│   ├── freedom/ 自由地图
│   ├── wealth/  财富管家
│   ├── museum/  人生博物馆
│   ├── report/  财富报告
│   └── profile/ 我的
├── app.ts
├── app.json
└── app.wxss
```

页面负责交互和展示，计算、校验与持久化集中在服务层。

## 本地数据

当前使用以下 Storage Key：

```text
retirement_plan.freedom_goal
retirement_plan.assets
retirement_plan.museum_collections
retirement_plan.snapshots
retirement_plan.reports
```

金额在模型和 Storage 中统一使用“元”，自由进度使用 `0–1`；页面通过公共格式化工具显示为元、万元和百分比。

财富快照按日期保存。同一天内多次新增、修改或删除资产，会更新当天快照；跨日期后才形成新的趋势节点。

## 启动方式

1. 安装并打开微信开发者工具；
2. 选择“导入项目”；
3. 项目目录选择本仓库根目录；
4. 确认 `project.config.json` 中的 `miniprogramRoot` 为 `miniprogram/`；
5. 点击“编译”。

项目使用开发者工具的 TypeScript 编译插件，不需要单独启动服务器。

## 建议测试流程

1. 清除开发者工具中的本地 Storage；
2. 在“自由”选择一个目标生活等级；
3. 在“财富”添加资产，确认自由进度同步更新；
4. 同日多次修改资产，确认快照数量不增加、当天金额更新；
5. 添加人生收藏，检查使用天数和每日成本；
6. 在拥有两个不同日期快照后生成财富报告；
7. 重新编译，确认所有数据仍然存在。

## 开发边界

当前明确不实现：

- AI 总结；
- 股票行情和收益预测；
- 自动投资建议；
- 银行或微信账单同步；
- 云存储和社交分享。
