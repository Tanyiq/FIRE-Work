四、新增数据模型
1. 财富快照模型

新增：

models/snapshot.ts

定义：

interface AssetSnapshot {

  id: string;

  // 快照日期 YYYY-MM-DD
  date: string;

  // 当前总资产，单位：元
  totalAsset: number;

  // 当前自由等级
  freedomLevel: string;

  // 当前自由进度 0-1
  freedomProgress: number;

  createdAt: number;
}

说明：

快照代表某个时间点用户的财富状态。

不是交易流水。

2. 财富报告模型

新增：

models/report.ts

定义：

interface WealthReport {

  id: string;

  // 报告日期

  // 资产变化
  assetChange: number;

  // 自由进度变化
  freedomChange: number;

  summary: string;

}
